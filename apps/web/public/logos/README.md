# Connector brand assets

These assets identify third-party services and remain trademarks of their respective owners.
The shared `vendor-icon.tsx` statically imports logos so Tally and Gate use the same files.

- n8n, Dify, Anthropic, Meta and Ollama: Simple Icons 16.26 (CC0-1.0), rendered to PNG.
- ServiceNow: the ServiceNow wordmark from https://commons.wikimedia.org/wiki/File:ServiceNow_logo.svg (public domain text logo; trademark rights retained), rendered to PNG.
- OpenAI, Copilot, LangGraph and CrowdStrike: existing curated product assets, rendered to PNG.
- Microsoft: the four-color Microsoft mark.

- Rapid7: official favicon from https://www.rapid7.com/favicon.ico, converted to PNG.
- Netskope: official favicon from https://www.netskope.com/wp-content/uploads/2019/04/cropped-favicon-192x192.png.
